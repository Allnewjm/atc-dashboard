Live sync

The board is board.json in the Allnewjm/atc-dashboard repo. This page checks it every 5 seconds and redraws when it changes. Reading works without a token. To edit here (reorder, status, done, add, deadline, duration), paste a GitHub token once. It is stored only in this browser (localStorage) and sent only to api.github.com. With a token, changes also show up faster (about 5 s instead of up to about 5 min).

  1. Open GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Name: ATC dashboard. Expiration: your choice (e.g. 90 days). Resource owner: Allnewjm.
  3. Repository access: Only select repositories → Allnewjm/atc-dashboard.
  4. Permissions → Repository permissions → Contents: Read and write (Metadata: read-only is added automatically). Nothing else.
  5. Generate, copy the token (starts with github_pat_), paste it below and press Save. Do this once per browser or phone.
